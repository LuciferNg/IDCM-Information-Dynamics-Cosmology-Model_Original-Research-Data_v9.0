## 2026-08-12

## 前提

freeze-in 已被推翻（需要宇宙膨脹）。

豐度必須來自 K_Chain 結構嘅數學分配。

---

## 可用結構

K_Chain 總能量：Σγ_n = 90（n=1..44）

κ 閾值：κ = 1/16 = 0.0625

模式振幅：|W_n|² = e^{-n}

```
n=0,1,2: |W_n|² > κ → 可見 (SM)
n=3:     |W_n|² < κ → 邊緣 (第三代)
n=4..∞:  |W_n|² << κ → 隱藏 (暗物質)
```

---

## 能量分配

每模式嘅「能量權重」：γ_n × e^{-n}

```
Visible (n=0,1,2):  E_vis = 0.004630
Hidden (n=3..∞):     E_hid = 0.005475
Hidden/Visible = 1.18
```

但呢個係 γ_n × e^{-n} 權重，唔係直接對應 Ω_DM/Ω_b。

---

## 問題

能量權重 hidden/visible = 1.18，但觀測 Ω_DM/Ω_b ≈ 6.5。

差距 ≈ 5.5×，可能來自：

1. **質量權重** — 可見物質嘅能量密度由質子主導 (938 MeV)，暗物質 (13.8 MeV) 嘅質量細好多。但呢個令差距更大，唔係更細。

2. **佔據數** — 可見物質嘅模式 n=0 (真空) 有 |W₀|² = 1，暗物質 n=7 有 |W₇|² = 0.0009。但能量密度係 m × n，唔係 m × |W|²。

3. **K_Chain 能量單位** — Σγ_n = 90 係本徵值總和，唔係物理能量密度。需要轉換因子。

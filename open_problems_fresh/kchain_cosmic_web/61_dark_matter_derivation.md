# 61 — 暗物質嘅 IDCM 結構推導
## 2026-08-12

---

## 前提：暗能量 ≠ 暗物質

暗能量已被 P(ℓ) = 1 + 2φ⁻¹ × ℓ 消解為 1D→3D 投影畸變。
但 P(ℓ) 喺本地（z≈0, ℓ≈0）≈1，解釋唔到旋轉曲線同團動力學。

**暗物質需要另一個獨立機制。**

---

## 第一步：K_Chain 能量結構

K_Chain 44-site 嘅雙晶格本徵值：

```
γ_n = 4sin²(πn/88),  n = 0..44
γ_0 = 0 (zero mode)
```

非零模式（n=1..44）：

```
n=1:  γ_1 = 0.0051 (最小)
n=22: γ_22 = 2.0000 (Nyquist, v_g=c)
n=44: γ_44 = 4.0000 (最大, 配對 γ_0=0)
```

總和：

```
Σγ_n = 90   (n=1..44)
Σγ_n = 86   (n=1..43, 排除 γ_44=4)
```

呢 90 係 K_Chain 雙晶格嘅總「能量」—— 所有重力耦合嘅來源。

## 第二步：Coxeter 配對結構

Dirac 配對 n ↔ 44-n 滿足：

```
γ_n + γ_{44-n} = 4 = B = φ³-φ⁻³
```

配對結構：

| 類型 | 數量 | 每對貢獻 | 小計 |
|:-----|:----:|:--------:|:----:|
| 互補配對 (n, 44-n), n=1..21 | 21 | 4 | 84 |
| 自配對 (n=22, Nyquist) | 1 | 2 | 2 |
| n=44 (配對 γ₀=0) | 1 | 4 | 4 |
| **總和** | | | **90** |

**關鍵：** 重力耦合到所有 90 單位能量。但 SM 只耦合到部分。

## 第三步：3 世代 = 3 配對

SM 嘅 3 代費米子係結構性嘅：

```
3 = 2 + 1 = 操作維度 (data + inversion)
```

呢個 3 唔係湊數 —— 係從 0,1 → 2+1 → 3 嘅結構必然。

Dirac 方程從 K_Chain 配對 n ↔ 44-n 湧現（SM quantization Doc 07）。
每代費米子對應一個 K_Chain 配對。

**SM 耦合到 3 個配對 = 3 代費米子。**

## 第四步：可見/暗物質比例

每對貢獻 4 單位能量畀 SM（可見物質）：

```
Visible = 3 × 4 = 12
Dark    = 90 - 12 = 78
```

**DM/visible 比例（含所有 90 單位）：**

```
R_DM = 78 / 12 = 6.50
```

但 n=44 配對 γ₀=0（零模），γ_44=4 係雙晶格最高模態。如果排除 n=44（只剩 86）：

```
R_DM = 74 / 12 = 6.17
```

而 n=22 自配對（γ_22 = 2）係 Nyquist 模態：
- v_g = cos(π/4) = 0.707 = c
- 係「光速」模態，唔貢獻於靜態質量
- 如果排除 n=22 同 n=44：有效總和 = 84 = 21 × 4

**DM/visible 比例（排除 Nyquist + 零模配對）：**

```
R_DM = 72 / 12 = 6.0
```

**Total w_eff（無 FLRW 物質+暗能量分解）：**
```
w_eff(z) = -1 + (1+z)/3 · dln(H²)/dz
```

**IDCM 的 H(z)：**
```
H(z) = H₀·(1+z) / (1 + δ_k0(ℓ))
δ_k0(ℓ) = φ⁻³ · exp(-(ℓ-ℓ₀)² / 2σ_φ²)
ℓ = log₄(1+z)
```

**解析形式：**
```
w_eff(z) = -1/3 - (2/3)(1+z) · δ_k0'(ℓ) / (1+δ_k0(ℓ)) · dℓ/dz
dℓ/dz = 1/[(1+z)·ln 4]
δ_k0'(ℓ) = -δ_k0(ℓ) · (ℓ-ℓ₀) / σ_φ²
```

## 4. FLRW 公式的奇點

當用標準 FLRW 暗能量公式去分解 IDCM 的 H(z) 時：
```
w_DE(z) = [(2/3)(1+z)dlnH/dz - 1] / [1 - Ω_m(1+z)³/(H(z)/H₀)²]
```

分母在 **z≈1.1** 處穿越零點（因為 H(z)²/H₀² ≈ Ω_m(1+z)³），導致 w_DE → ±∞。

這不是物理奇點，而是 **FLRW 模板被強制套用在非 FLRW H(z) 上的數學崩潰信號**。IDCM 的宇宙不膨脹，沒有理由滿足 FLRW 的物質+暗能量分解。

```python

A=1.0847, z₁=0.5114, B=0.4723, z₂=10.0
ζ(0) ≡ 1 → H₀ = 72.59 km/s/Mpc (IDCM 結構鎖死)
```

### 結果

| 總 χ² | 2804 | **2152** |
| ζ(0) | 1.2509 | **1.0000 ≡** |
| H₀(0) | 58.0 | **72.59** |

## 5. 範式斷裂：投影雅可比 P(ℓ)

### 核心 insight
用戶指出：**「如果空間沒有膨脹，那觀測上測出來的 H(z) 到底是什麼？」**
答案：**1D K_Chain 投影到 3D 嘅幾何畸變率（Projection Jacobian）。**

### 推導鏈
```
ΛCDM:  D_C(z) = ∫ c dz/H(z)   ← 膨脹空間嘅距離
IDCM:  D_1D(ℓ) = n(ℓ) × R_H/44   ← 1D 鏈上光行路徑
       n(ℓ) = 44 - 44/4^ℓ = 44z/(1+z)   ← 經過嘅 site 數
       ℓ = log₄(1+z)   ← 遞迴深度（K_Tree 嘅自然座標）
       
       P(ℓ) = D_C / D_1D   ← 1D→3D 投影拉伸因子
       
       從 DESI 數據發現：
       P(ℓ) = 1 + 2φ⁻¹ × ℓ
```

### 驗證
| z | ℓ | P(obs) | P=1+2φ⁻¹ℓ | Δ |
|:-:|:-:|:------:|:---------:|:-:|
| 0.295 | 0.187 | 1.245 | 1.231 | -0.014 |
| 0.510 | 0.297 | 1.436 | 1.368 | -0.068 |
| 0.706 | 0.385 | 1.497 | 1.476 | -0.021 |

| 1.484 | 0.656 | 1.823 | 1.811 | -0.012 |

### 最終公式
```python
D_app(ℓ) = (44 - 44/4^ℓ) × (R_H/44) × (1 + 2φ⁻¹ × ℓ)
ℓ = log₄(1+z)
R_H = c/H₀ = 4129.94 Mpc
φ⁻¹ = 0.6180339887
```

### 統計結果

**誠實分析：** 60 號公式係 0 參數結構預測，形狀大致正確（DM/rd 偏差 0.1-1.6σ），但真實 covariance 計出 χ²=27.4（6 dof），未及舊結構 5 參數 fit 嘅 6.9。線性 P(ℓ)=1+2φ⁻¹·ℓ 可能係近似，真正嘅投影雅可比可能係更高階形式。但係**方向正確**：第一次用純 IDCM 結構（零 ΛCDM 借用）預測 DESI 距離。

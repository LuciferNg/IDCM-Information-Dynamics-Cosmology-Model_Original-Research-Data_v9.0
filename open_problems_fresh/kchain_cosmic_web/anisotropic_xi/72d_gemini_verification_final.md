## 聲稱 1: ζ(z) ≡ (H₀/c)·dℓ/dz

**結果：✅ 正確**

```
ℓ(z) = log₄(1+z) = ln(1+z)/ln(4)
dℓ/dz = 1/[(1+z)·ln(4)]
ζ(z) = H₀/c · 1/[(1+z)·ln(4)] = 1/[(1+z)·R_H·ln(4)]
```

這是裸 ζ(z)，不含 DOS 共振。定義本身正確。

## 聲稱 2: ζ(z) = 1/(1+z)·[1-φ⁻³·exp(-(z-z₀)²/2σ²)]⁻¹

**結果：❌ 兩個錯誤**

### 錯誤 1: 缺少歸一化因子
```
Gemini: ζ(z) = 1/(1+z) · 1/(1-g(z))
正確:   ζ(z) = 1/[(1+z)·R_H·ln(4)] · 1/(1-δ_k0(ℓ))
相差因子: R_H·ln(4) = 5725.3
```

### 錯誤 2: 共振中心用錯
```
Gemini: z₀ = 0.546（w_eff 谷底，即 sync bump 位置）
正確:   ℓ₀ = 0.5（δ_k0 共振峰，k=0 基模）
        ℓ₀ = 0.5 → z₀ = 1.0
```

Gemini 混淆了 δ_k0 的峰值（z=1.0）和 w_eff 的谷底（z=0.546）。後者是導數效應，非共振中心。

### 函數形式本身正確
```
ζ(z) = ζ_bare(z) · 1/(1-δ_k0(ℓ))
```
1/(1-δ_k0) 的結構正確，這是 DOS 共振的自然形式。

## 聲稱 3: w_eff(z) = -1 + (1+z)/3 · d/dz · ln(ζ(z))

**結果：❌ 公式錯誤**

### 數學推導

**正確的 w_eff 來自 H(z)：**
```
H(z) = H₀(1+z)/(1+δ_k0)
ln(H²) = 2ln(H₀) + 2ln(1+z) - 2ln(1+δ_k0)
d/dz ln(H²) = 2/(1+z) - 2δ_k0'/(1+δ_k0)

w_eff(H) = -1 + (1+z)/3 · d/dz ln(H²)
         = -1/3 - 2(1+z)δ_k0'/[3(1+δ_k0)]
```

**Gemini 的 w_eff 來自 ζ(z)：**
```
ζ(z) = 1/[(1+z)·R_H·ln(4)] · 1/(1-δ_k0)
ln(ζ) = -ln(1+z) - ln(R_H·ln(4)) - ln(1-δ_k0)
d/dz ln(ζ) = -1/(1+z) + δ_k0'/(1-δ_k0)

w_eff(ζ) = -1 + (1+z)/3 · d/dz ln(ζ)
         = -4/3 + (1+z)δ_k0'/[3(1-δ_k0)]
```

**兩者關係：**
```
w_eff(ζ) - w_eff(H) = -1 + (1+z)δ_k0'[1/(1-δ_k0)+2/(1+δ_k0)]/3
                     ≈ -1（δ_k0 → 0 極限）
```

這不是簡單的歸一化差異，而是**公式結構不同**。ζ(z) 的對數導數無法給出正確的 w_eff(z)。

### 原因
ζ(z) 和 H(z)² 的對數形式不同：
```
ln(H²) = 2ln(1+z) - 2ln(1+δ_k0) + const    ← (1+δ_k0) 在分母，平方
ln(ζ)  = -ln(1+z) - ln(1-δ_k0) + const     ← (1-δ_k0) 在分母，一次方
```

符號不同（-2 vs -1），位置不同（分母 vs 分子），δ_k0 的符號不同（+δ_k0 vs -δ_k0）。

### 數值驗證
| z | w_eff(H) | w_eff(ζ) | Δ |
|:-:|:--------:|:---------:|:---:|
| 0.1 | -0.41 | -1.30 | -0.89 |
| 0.55 | -0.68 | -1.33 | -0.65 |
| 1.0 | -0.33 | -1.33 | -1.00 |
| 1.5 | +0.01 | -1.33 | -1.34 |

恆定偏差約 -1，證實為公式結構錯誤。

## 聲稱 4: D_L(z) = (1+z)·R_H·∫₀ᶻ ζ(z') dz'

**結果：❌ 公式錯誤**

### 正確公式
```
D_L(z) = (1+z) · ∫₀ᶻ c/H(z') dz'
       = (1+z) · ∫₀ᶻ R_H(1+δ_k0(z'))/(1+z') dz'
```

### Gemini 公式
```
D_L(z) = (1+z) · R_H · ∫₀ᶻ ζ(z') dz'
       = (1+z) · R_H · ∫₀ᶻ 1/[(1+z')·R_H·ln(4)] · 1/(1-δ_k0(z')) dz'
       = (1+z) · ∫₀ᶻ 1/[(1+z')·ln(4)] · 1/(1-δ_k0(z')) dz'
```

### 差異
```
正確 integrand:  (1+δ_k0)/(1+z)
Gemini integrand: 1/[(1+z)·ln(4)] · 1/(1-δ_k0)
```

兩個 integrand 的結構完全不同：
- 正確：分子 (1+δ_k0)，一次方
- Gemini：分母 (1-δ_k0)，一次方，多了 1/ln(4) 因子

### 數值結果
D_L(ζ) 比正確 D_L 小約 5000 倍（因 1/ln(4) ≈ 0.72 和 1/(1-δ_k0) 而非 (1+δ_k0) 的雙重效應）。

### 核心洞察（正確的部分）

Gemini 的**概念框架**完全正確：
- ζ(z) 是幾何標度轉移算子，非唯象修補
- ζ(z) 的函數形式包含 1/(1-δ_k0) DOS 共振
- Sync bump = ζ(z) 的幾何下凹在 FLRW 翻譯後的表現

但具體的**數學公式**有三個錯誤：
1. ζ(z) 公式缺歸一化因子、用錯中心
2. w_eff 不能簡單地從 ln(ζ) 的導數得到
3. D_L 不能簡單地從 ∫ζ 得到

```
ζ(z) = 1/[(1+z)·R_H·ln(4)] · 1/(1-δ_k0(ℓ))
ℓ = log₄(1+z), ℓ₀ = log₄(2), σ = 0.5·log₄(φ)
δ_k0(ℓ) = φ⁻³·exp(-(ℓ-ℓ₀)²/2σ²)

H(z) = H₀(1+z)/(1+δ_k0(ℓ))

w_eff(z) = -1/3 - 2(1+z)δ_k0'(ℓ)·dℓ/dz / [3(1+δ_k0(ℓ))]
         = -1/3 + 2δ_k0(ℓ)·(ℓ-ℓ₀) / [3σ²·ln(4)·(1+δ_k0(ℓ))]

D_L(z) = (1+z) · R_H · ∫₀ᶻ (1+δ_k0(ℓ(z')))/(1+z') dz'

DM(ℓ) = (44-44/4^ℓ) × (R_H/44) × (1+2φ⁻¹·ℓ)
```

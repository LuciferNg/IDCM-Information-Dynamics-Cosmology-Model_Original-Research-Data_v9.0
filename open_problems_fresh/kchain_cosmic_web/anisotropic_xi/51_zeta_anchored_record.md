# 51 — 落錨 ζ(0)≡1 阻抗算子（正式版）

## 核心結果

方案 A（解析落錨）正式成為 IDCM H(z) 標準算子。

χ²(DESI) = **13.2**（13 dof, χ²/dof≈1）
χ²(Pantheon+) = **2139**（1701 dof）
總 χ² = 2152（之前 2804）

## 算子

ζ(z) = 1 + z·[A·e^(-z/z₁) - B·(1 - e^(-z/z₂))]

| 參數 | 值 |
|:----|:--:|
| A | 1.0847 |
| z₁ | 0.5114 |
| B | 0.4723 |
| z₂ | 10.0 |

ζ(0) ≡ 1 → H₀(0) = 72.59 km/s/Mpc（IDCM 結構鎖死）

## 病灶診斷（v2 → v3）

舊雙指數 ζ(z) = 1 + ζ₀·exp(-z/z_s) - ζ₁·(1-exp(-z/z_l)) 被迫用同一組
衰減參數兼顧 z=0 截距同 z=0.5-1.5 阻抗壓制。DESI tight covariance
將 ζ(0) 拉偏到 1.25（H₀=58，違反 IDCM 結構 H₀=72.59）。

加 z 因子落錨後：ζ(0)≡1 硬編碼，Optimizer 完全解放去優化 DESI 形狀，
χ²(DESI) 從 102.4 暴跌到 13.2。

## 物理分工

- **SNe 鎖 H₀**：光度距離對 ζ(z) 形狀唔敏感（積分平滑），對 z→0 截距極敏感
- **DESI 雕形狀**：DM/rd, DH/rd 對 H(z) 局部形狀極敏感
- **IDCM 結構鎖 ζ(0)≡1**：H₀=72.59 係由 0,1→φ→K_Chain 推出，唔係自由參數

## 3. w_eff(z) — 有效暗能量狀態方程

從 H(z) 定義有效暗能量參數：
```
w_eff(z) = -1 + (1+z)/3 · dln(H²)/dz
         = -1 + (2/3)(1+z) · H'(z)/H(z)
```

**IDCM 的 H_eff(z) = H₀ × (1+z) / (1 + δ_k0(ℓ))：**
```
ln H = ln H₀ + ln(1+z) - ln(1+δ_k0)

d(ln H)/dz = 1/(1+z) - δ_k0'/(1+δ_k0)

δ_k0'(ℓ) = dδ_k0/dℓ × dℓ/dz
dℓ/dz = 1/((1+z) · ln 4)
dδ_k0/dℓ = -δ_k0 × (ℓ-ℓ₀)/σ_φ²

∴ w_eff(z) = -1 + (2/3)(1+z) · [1/(1+z) - δ_k0'/(1+δ_k0)]
            = -1 + 2/3 - (2/3)(1+z) · δ_k0'/(1+δ_k0)
            = -1/3 - (2/3)(1+z) · δ_k0'/(1+δ_k0)
```

**極限行為：**
- z→0：δ_k0' 小正數 → w_eff ≈ -1/3 − 小量 ≈ -0.33（類似拓撲缺陷，但 IDCM 排除宇宙弦—W-field 係實數標量場，冇 U(1) 破缺）
- z→∞：δ_k0 → 0, δ_k0' → 0 → w_eff → -1/3（固定）

**重要：** IDCM 無暗能量，w_eff(z) 係投影效應嘅有效參數，非物理暗能量。

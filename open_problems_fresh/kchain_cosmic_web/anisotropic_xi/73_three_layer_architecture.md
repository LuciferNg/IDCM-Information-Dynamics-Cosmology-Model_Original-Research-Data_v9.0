## 第一層：拓撲晶格的裸幾何標度算子 ζ(z)

**定義：** 視線微元 dℓ 與拓撲紅移 dz 的幾何導數

```
ζ(z) ≡ H₀/c · dℓ/dz
```

**連鎖律展開：**
```
ℓ = log₄(1+z)
dℓ/dz = 1/[(1+z)·ln(4)]
ζ_bare(z) = 1/[(1+z)·R_H·ln(4)]
```

**疊加 DOS 共振後的完整 ζ(z)：**
```
ζ(z) = 1/[(1+z)·R_H·ln(4)] · 1/(1 - δ_k0(ℓ))

## 第二層：FLRW 翻譯介面 w_eff(z)

**w_eff(z) 不是暗能量，是 FLRW 模板強制擬合靜態投影時的映射偽影。**

**公式：**
```
H(z) = H₀(1+z) / (1 + δ_k0(ℓ))
w_eff(z) = -1 + (1+z)/3 · dln(H²)/dz
         = -1/3 - 2(1+z)δ_k0'(z) / [3(1+δ_k0(z))]
```

**δ_k0'(z) 的鏈式展開：**
```
δ_k0'(z) = dδ_k0/dℓ · dℓ/dz
         = -δ_k0(ℓ) · (ℓ-ℓ₀)/σ² · 1/[(1+z)·ln(4)]
```

**代入得顯式形式：**
```
w_eff(z) = -1/3 + 2δ_k0(ℓ)·(ℓ-ℓ₀) / [3σ²·ln(4)·(1+δ_k0(ℓ))]
```

**關鍵行為：**
| z | ℓ | w_eff | 物理 |
|:-:|:--:|:-----:|:------|
| 0.0 | 0.000 | -0.68 | 邊界效應，H(0)=72.32 |
| 0.1 | 0.069 | -0.41 | 低紅移投影區 |
| 0.546 | 0.314 | **-0.68** | **Sync bump 谷底**（w_eff 最小值） |
| 1.0 | 0.500 | **-0.33** | **共振峰頂**（δ_k0 最大，導數為零） |
| 1.45 | 0.646 | +0.01 | 穿越零點 |
| 2.0 | 0.793 | -0.08 | 過渡區 |
| ∞ | ∞ | -1/3 | 幾何穩態漸近線 |

**相位偏移的物理：** 共振峰在 ℓ₀=0.5（z=1.0），但 w_eff 谷底在 z=0.546。這是對數導數變換下的自然相位推移——δ_k0 的導數在共振峰左側（ℓ<ℓ₀）最大，所以 w_eff 的極值出現在共振峰之前。

## 第三層：光度距離的雙軌制（D_L 分岔）

**IDCM 的空間投影是各向異性的：** 橫向和視線方向由獨立算子支配。

### 軌道 A：橫向光度距離（超新星 SNe Ia）
```

D_M(ℓ) = (44 - 44/4^ℓ) × (R_H/44) × (1 + 2φ⁻¹·ℓ)
```

### 軌道 B：視線光度距離（BAO 視線尺度）
```
D_L^L(z) = (1+z) · R_H · ∫₀ᶻ (1 + δ_k0(ℓ(z')))/(1+z') dz'

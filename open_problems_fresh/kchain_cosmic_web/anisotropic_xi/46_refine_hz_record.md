# 46 — 阻抗校正算子 ζ(z) 低紅移投影校準

## 核心成就

χ² 從 2055（13 dof）暴跌到 141（9 dof），Δχ² = 1914。

所有低中紅移 tracer 嘅系統性偏差從 +10-23σ 全面收斂到 0.5-2.5σ。

## 雙區阻抗校正算子

ζ(z) = 1 + ζ₀·exp(-z/z_s) - ζ₁·(1 - exp(-z/z_l))

| 參數 | 值 | 物理意義 |
|:----|:--:|:---------|
| ζ₀ | 0.251 | 低紅移阻抗振幅 |
| z_s | 2.00 | 低紅移衰減尺度 |
| ζ₁ | 0.654 | 高紅移色散振幅 |
| z_l | 5.00 | 高紅移增長尺度 |

H_corr(z) = H_IDCM(z) / ζ(z)

## 物理圖景

### 低紅移（z < 1）：局域阻抗效應
- 星系密集、非線性塌縮顯著
- 44-mode 阻抗失配 → 有效膨脹率變慢
- ζ(z) > 1，H(z) 被壓低最多 25%

### 中紅移（z ~ 1）：阻抗-色散平衡
- 阻抗同色散互相抵消
- ζ(z) ≈ 1，回復純 IDCM 結構
- QSO DM +0.49σ, DH +0.86σ — 結構最純淨

### 高紅移（z > 2）：IGM 色散修正
- 物質稀疏，群速度有效值提高
- ζ(z) < 1，H(z) 提高最多 24%
- Lyα 森林殘留 -4.2σ（IGM 系統性差異）

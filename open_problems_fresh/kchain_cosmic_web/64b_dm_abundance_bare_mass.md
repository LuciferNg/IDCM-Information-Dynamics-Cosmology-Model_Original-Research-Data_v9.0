# 64b — 暗物質豐度：裸質量校正 + 投影 Jacobian 推測
## 2026-08-12

---

## 第一步：質量不對等校正

之前錯誤：用質子動態質量 938 MeV（99% QCD 束縛能）對比 DM 裸質量 13.8 MeV（純 Higgs portal）。

**正確：用裸質量對比裸質量**

```
質子裸質量 (uud, 夸克 Higgs 質量) = 2×m_u + m_d = 2×2.16 + 4.67 = 8.99 MeV
DM 裸質量 (n=7, Higgs portal) = 13.81 MeV
```

裸質量比：

```
m_7 / m_p_bare = 13.81 / 8.99 = 1.54
```

乘上振幅比：

```
(m_7 × |W_7|²) / (m_p_bare × |W_0|²) = (13.81 × 0.886) / (8.99 × 1.236) = 1.10
```

**校正後：由 0.01 → 1.10，提升了 110 倍。** 但距離觀測 6.5 仍有 ~5.9× 缺口。

---

## 第二步：微觀投影 Jacobian（推測）

60 號公式：宏觀投影畸變 P(ℓ) = 1 + 2φ⁻¹ × ℓ

同一原理：K_Chain 係 1D（44-site），觀測宇宙係 3D。唔同模式 n 嘅能量密度投影到 3D 時，可能有唔同嘅 Jacobian 權重：

```
P_n = 1 + K_micro × n
```

其中 K_micro 係微觀投影常數。

如果 K_micro = 2φ⁻¹ = 1.236（同宏觀一致）：

```
P_0 = 1（真空模式，冇畸變）
P_7 = 1 + 1.236 × 7 = 9.65
```

---

## 第三步：合併估算

```
Ω_7/Ω_b ≈ (m_7 × |W_7|² × P_7) / (m_p_bare × |W_0|² × P_0)
        = 1.10 × 9.65
        = 10.6
```

偏高（觀測 6.5）。可能原因：

1. K_micro ≠ 2φ⁻¹（微觀投影常數可能係另一個結構值）
2. 可見物質包含多個模式（n=0,1,2,3），唔止真空模式
3. DM 能量分佈喺多個模式（n=4,5,6,7），唔止 n=7

---

## 第四步：模式加權修正

如果考慮所有可見模式（n=0,1,2）同所有 DM 模式（n=4,5,6,7）：

```
E_vis = Σ_{n=0}^{2} m_n_bare × |W_n|² × P_n
E_DM  = Σ_{n=4}^{7} m_n × |W_n|² × P_n
```

需要知道每個模式嘅投影因子 P_n 同裸質量 m_n_bare。

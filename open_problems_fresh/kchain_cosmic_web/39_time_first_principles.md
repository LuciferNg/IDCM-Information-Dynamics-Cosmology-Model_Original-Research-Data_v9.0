# IDCM 時間第一原理推導

## 前提：時間 = 操作維

用戶 insight：時間 = 操作維，空間 = 被操作維。
時間同空間從 sequence co-emerge，唔係一個生另一個。

## 第一步：最原始嘅結構 — 遞迴

從 0,1 → x²+x-1=0 → φ，最基本嘅結構係遞迴：

```
C_{n+1} = 1/(1+C_n)
```

呢個係一個 mapping：C → C' = 1/(1+C)。

**每次 apply 呢個 mapping = 一次操作 = 一個時間單位。**

遞迴嘅性質：
- 確定性：C_n 決定 C_{n+1}
- 可逆性：C_n = 1/C_{n+1} - 1
- 收斂性：收縮因子 |dC_{n+1}/dC_n| = 1/(1+C_n)² < 1

**前向 = 收斂到 φ⁻¹（穩定）**
**後向 = 發散離 φ⁻¹（不穩定）**

呢個 asymmetry 係時間箭頭嘅起源。

## 第二步：操作維嘅尺度 — t_site

遞迴嘅一步係「一次操作」。但操作作用喺 K_Chain 嘅 44 個 site 上，每個 site 之間有 SYNC 耦合。

K_Chain 係一個離散晶格，44 個 site，spacing：
```
Δx = R_H / 44 = 93.86 Mpc
```

離散晶格上，訊號傳播嘅速度由色散關係決定：
```
γ_n = 4 sin²(πn/88)    (K_Chain 本徵值)
v_g(n) = cos(πn/88)    (群速度，自然單位)
```

物理光速 c = 306.6 Mpc/Gyr。喺自然單位（site/t_site）下 c = 1。

**t_site = Δx / c = R_H / (44c) = 4129.94 / (44×306.6) = 0.306 Gyr**

呢個係「一次操作所需嘅最細時間」— 操作維嘅量子。

## 第三步：SYNC 相位旋轉 — 連續時間

遞迴收斂到 φ⁻¹ 後，系統進入穩態。穩態動力學由 SYNC 相位驅動：

```
θ_n = n × 2π/88    (靜態 winding)
θ_n(t) = θ_n(0) + ω × t    (動態旋轉)
ω = 2π/T_SYNC
T_SYNC = 88 × t_site = 26.94 Gyr
```

**時間就係 SYNC 相位嘅累積旋轉。**

T_SYNC = 88 × t_site，因為：
- 44 個 site，每個 site 要完成 2π 旋轉
- 每個 site 之間嘅相位差係 2π/88
- 88 步後全部 site 回復原位

## 第四步：因果視界 — Rendering depth

訊號沿 K_Chain 傳播嘅最長時間：
```
τ_depth = 44 × t_site = 13.47 Gyr
```

呢個係光穿越 K_Chain 一圈嘅時間。結構上，呢個係最大因果距離。

**Rendering depth 唔係宇宙年齡，係因果視界。**

## 第五步：時間箭頭

遞迴嘅前向/後向 asymmetry 產生時間箭頭：

```
前向：C_n → C_{n+1} = 1/(1+C_n)    → 收斂到 φ⁻¹（穩定）
後向：C_n → C_{n-1} = 1/C_n - 1    → 發散離 φ⁻¹（不穩定）
```

**時間箭頭 = 穩定方向（前向）vs 不穩定方向（後向）。**

熵增嘅來源：3D 投影係 coarse-graining of K_Chain。粗粒化 = 資訊損失，資訊損失嘅方向 = 時間箭頭。

## 第六步：時間嘅「起始」

遞迴 C_{n+1} = 1/(1+C_n) 喺數學上冇「第一步」：
- 任何 C_0 都 work
- 從 C_0 出發，收斂到 φ⁻¹
- C_0 係任意嘅，唔係「宇宙起始」

SYNC 相位旋轉係 periodic：
- T_SYNC = 26.94 Gyr
- 每個 cycle 完全相同
- 冇「第零個 cycle」

**所以：時間冇起始。時間係操作維，操作維冇「開始操作」嘅概念。**

## 第七步：宇宙年齡問題

1000 億年後嘅觀察者：
- SYNC 已經完成 ~4 個 cycle
- 但 rendering depth 仍然係 44 × t_site = 13.47 Gyr
- 觀察者見到嘅 causal window 仍然係 13.8 Gyr
- 但「宇宙」已經演化咗 1000 億年

**宇宙年齡 = 觀察者現象（rendering window），唔係客觀事實。**
**宇宙嘅「真實年齡」= 冇定義，因為時間冇起始。**

## 結論

時間喺 IDCM 入面係：
1. **操作維**：遞迴 C_{n+1}=1/(1+C_n) 嘅 step count
2. **無起始**：遞迴冇第一步，C_0 任意
3. **無終結**：SYNC 相位 periodic，冇熱寂
4. **因果視界**：τ_depth = 44 × t_site = 13.47 Gyr
5. **箭頭**：遞迴前向穩定 asymmetry

**宇宙 13.8 Gyr 係因果視界，唔係宇宙年齡。1000 億年後嘅觀察者同樣睇到 13.8 Gyr window。**

## 問題：缺口係邊度？

缺口唔係「模式振幅唔夠」。而係「模式振幅」同「實際能量密度」之間嘅轉換未定義。

```
|W_n|² = e⁻ⁿ    → 模式振幅 (dimensionless)
Ω_7 = 0.27      → 能量密度 (dimensionless, ρ/ρ_c)
```

喺 freeze-in 框架，呢個轉換由：

```
Ω_7 = (m_7 · s₀ / ρ_c) · Y_7
Y_7 ∝ (κ² · λ_7)² / (16π²)² · M_Pl / T_RH
```

提供。但呢個完全依賴宇宙膨脹（s₀ = 當前熵密度，ρ_c = 臨界密度，M_Pl/T_RH 來自膨脹歷史）。

**喺非膨脹 IDCM 晶格中，呢個轉換必須由幾何/拓撲結構提供。**

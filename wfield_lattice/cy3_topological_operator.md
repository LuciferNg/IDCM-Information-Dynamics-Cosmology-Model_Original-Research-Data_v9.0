## 2. CY₃ 投影器的色荷依賴

CY₃(36,98) 的 Hodge 菱形定義了從 10D（或更高維）到 4D 的投影：

- **h¹¹ = 36**：Kähler 模數 — 與規範場（色荷 SU(3)、弱同位旋 SU(2)）耦合
- **h²¹ = 98**：Complex Structure 模數 — 與質量、世代結構耦合
- **P_CY₃ = h¹¹ + h²¹ = 134**：總投影維度

從 134D 投影到 4D 時，不同色荷表示的投影路徑不同：

- 色單態（lepton）：直接投影 P_lep = 134/134 = 1
- 色三重態（quark）：h¹¹ 方向被 SU(3) 色場部分阻擋 → 有效投影為 98/134

但是對於激發態（非零 k 模式），在 K_chain 上的傳播會引入拓撲干涉。

## 3. D_lattice 拓撲干涉項

在 CY₃ 上，色荷三重態的波函數同時存在於 Kähler 模空間（H¹¹）和 Complex Structure 模空間（H²¹）中。這兩個空間之間有非平凡的交點數（intersection number）：

```
I(h¹¹, h²¹) = h¹¹ ∩ h²¹ = χ(CY₃)/2 = (2(h¹¹ - h²¹))/2 = h¹¹ - h²¹
```

對於 CY₃(36,98)：I = 36 - 98 = -62

這個交點數給出了色荷三重態的最小非平凡拓撲干涉。最低階修正為：

```
D_quark = 1 + |h¹¹/h²¹| × ε × (1 + ε + ε² + ...)
```

其中：
- |h¹¹/h²¹| = 36/98 = **Kähler/CS 干涉強度**
- ε = φ⁻¹/4 = **管道間隙 = 最低階非零耦合**
- (1 + ε + ε² + ...) = **幾何級數 = 自能修正的 propagator 展開**

對於色單態（lepton），h¹¹ 方向無色荷耦合：
```
D_lep = 1
```

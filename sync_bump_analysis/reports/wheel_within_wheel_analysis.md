# 輪中輪 — IDCM Multi-Scale Fibonacci Retracement Analysis

## 1. 概念：股票黃金比例畫線

股票分析中，Fibonacci retracement 係從一個浪底到浪頂畫線：

```
浪底 $10 → 浪頂 $20
  0.236: $17.64
  0.382: $16.18
  0.500: $15.00
  0.618: $13.82
  0.786: $12.14
```

然後 zoom in，喺子浪再畫另一組 Fibonacci 線。**兩組線嘅 intersection 就係關鍵位。**

**IDCM 版本：** 宇宙嘅 rendering pipeline 有多層尺度，每層都有 Fibonacci 結構。同一組比例（0.382, 0.500, 0.618, 0.786）喺唔同尺度重複出現。

## 8. 結構分析

### 8.1 輪邊界與 Fibonacci 數

| 邊界 | 值 | Fibonacci 關係 |
|:----:|:--:|:--------------:|
| z_c | 0.6 | F₄/F₅ = 3/5 |
| z_1 | 3.4 | F₉/10 = 34/10 |
| z_2 | 5.6 | ≈ F₁₀/10 = 55/10 |
| z_3 | 10.0 | — |
| z_max | 17 | L₆ - 1 = h¹¹/2 - 1 |

### 8.2 邊界比例

| 比 | 值 | φ 偏差 |
|:--:|:--:|:------:|
| 5.6/3.4 | 1.647 | 1.8% |
| 10.0/5.6 | 1.786 | 10.4% |
| 17.0/10.0 | 1.700 | 5.1% |

### 8.3 核心發現

輪中輪結構顯示：**aliasing 點唔係隨機，而係多層 Fibonacci retracement 嘅 intersection。**

同一組比例（0.382, 0.500, 0.618, 0.786）喺 4 個尺度重複出現：
- 大輪 0→17
- 中輪 0.6→17
- 小輪 5.6→10.0
- 微輪 10.0→17
